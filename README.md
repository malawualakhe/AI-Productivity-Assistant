Setup Instructions
Creating a Project
Log into ChatGPT on web or Windows app.
Click Projects in the sidebar → New Project.
Name your project, choose an icon/color, and click Create
2
 .
Adding Custom Instructions
Open the project → click three dots (⋮) → Add Instructions.
Define role, tone, goals, or any other specific guidance.
Save; instructions now apply to all future chats in the project 
2
.
Uploading Files
Click Add Files within the project.
Drag and drop or browse for documents, spreadsheets, images, or scripts.
Uploaded files are accessible by all project chats 
2
.
Moving Existing Chats
Hover over a chat → click three dots → Add to Project or drag into project window.
Chats inherit project instructions and context; you can later remove them if needed 
2
.
Sharing Projects
Click Share in the project → invite individuals, groups, or via a link.
Set permissions as edit or chat.
Free and paid users have limitations on number of files and collaborators 
2
.
Managing Projects
Delete projects when complete (removes chats, files, and instructions) or organize by archiving/moving chats.
Regular maintenance ensures files and conversations remain relevant
